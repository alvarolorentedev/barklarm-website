Welcome to the Barklarm user guide! This guide shows you how to get started on observing your projects better.

## What is Barklarm?

Barklarm puts CI build status and monitoring alerts in your system tray. Connect the services you use and get a native desktop notification when a status changes. Barklarm is available for macOS, Windows, and Linux.

## Is Barklarm for me?

If you are running production services and want to be able to react as soon as possible to issues without the mental bandwidth of checking different places manually, I would say yes!

## Ready to get started?

Find out how to define and use your observers in [Quick Start](/docs/quick-start). Or visit the [page](https://www.barklarm.com/) and [its repo](https://github.com/alvarolorentedev/barklarm-app) and start exploring.
