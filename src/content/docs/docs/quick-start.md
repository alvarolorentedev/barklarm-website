## Install Barklarm

[Download the latest Barklarm release](https://github.com/alvarolorentedev/barklarm-app/releases/latest), then choose the installer for your computer.

| Platform | Installer |
| --- | --- |
| **macOS** | Open the `.dmg` for Apple silicon or Intel. |
| **Windows** | Run the x64 `.exe` or `.msi` installer. |
| **Linux** | Use a `.deb`, `.rpm`, or AppImage for your architecture. |

:::note[Upgrading from v2?]
Download and install v3 manually. Version 2 does not update itself to v3.
:::

## Add your first observer

1. Start Barklarm and choose **Configure** from its system tray menu.
2. In **Observers**, choose **New observer** and select a service. Add an alias and fill in the settings for your integration.
3. Open the Barklarm tray menu to see the observer’s status.
