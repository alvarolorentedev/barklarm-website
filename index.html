Common questions

What is Barklarm?
A desktop app for CI build status and monitoring alerts.
Which tools does it support?
GitHub Actions, Azure DevOps, Datadog, Sentry, New Relic, and CCTray are among the supported integrations.
Is Barklarm free?
Yes. It’s free and open source on macOS, Windows, and Linux.
